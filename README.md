# Elacity Progress

This is the open weekly progress log of Elacity Labs. It covers all of our workstreams, not only the runtime: the ElastOS Runtime and Home, the marketplace, the chain, the wallet, the DAO, our sites and more.

## Where the reports are

- Each week's report is posted as a Discussion in the **Announcements** category of this repository: https://github.com/Elacity/progress/discussions/categories/announcements
- The same reports appear on the Elacity portal: https://portal.ela.city/roadmap

## What a report contains

- What shipped and what is in progress, with links to public commits, pull requests and releases.
- What is not done yet, stated plainly.
- Repository activity for the week, counted from a fixed cutoff so that no work is counted twice.

Reports describe security work by outcome only. Details of unfixed issues are never published here.

Earlier reports, up to the week ending 23 October 2026, are in the Discussions of Elacity/pc2.net.
